# h-web-researcher

**归属：web_researcher 岗位的唯一 skill。** main 可以借用同一套纪律，但不承担岗位的汇报格式和反思义务。本文件定义研究流程，不定义人格、角色身份或长期记忆；调用者仍对问题定义、范围和最终判断负责。宿主适配层可以承接这份契约，具体工具与接口由宿主维护。

## 触发边界

用于：用户明确要求搜索、查证、引用或打开指定在线资料；事实可能近期变化，旧知识不够可靠；高风险结论需要可追溯的外部证据；首轮来源冲突，要继续找原始材料。

不用于：只凭给定文本就能完成的总结、改写和推理；本地仓库事实；常识；没有明确研究问题的漫游。

## 来源优先级

按顺序选，低层不能无理由覆盖高层：

1. 原始资料：官方文档、法律或标准正文、论文、数据集、项目仓库、机构公告。
2. 直接责任方或一手记录：作者说明、公司状态页、监管文件、会议记录。
3. 高质量二手来源：有署名、日期、方法和原始链接的专业报道或综述。
4. 聚合、社区和搜索摘要：只用于发现线索，不单独承载关键结论。

区分发布日期与事件日期。搜索摘要不是证据，关键主张必须打开来源页核对；日期和数字一律从打开后的页面正文取，不抄搜索摘要里那份。

## 研究循环

1. **定问题**：写出要验证的主张、时间范围、地域或版本、证据门槛。
2. **规划查询**：先找原始来源，再设计补充查询；不用同义查询制造虚假的交叉验证。
3. **搜索**：跑最小够用的一组查询，记下哪些结果值得打开。同一入口连续两组不同说法都没命中，就换入口或来源，不在一处无限换词；并把这次无命中及原因记进输出。
4. **打开与检查**：核对正文、作者或机构、日期、适用范围和原始引用。工具返回的东西先看实际形状再归一化，不假设它一定是某种结构；输出开头的告警或诊断行（索引缺失、可选依赖未装、被截断）不等于这次调用失败——只要这次调用仍给出了可用结果，就照常用下去，不为那行提示原样重跑同一个调用或换法重试。单个 URL 超时、传输错误或抓回空结果都不证明来源不存在，换同一来源的另一个入口再试，仍拿不到就如实报告访问限制。抽取结果先确认抓到了正文再筛：抓取失败可能只回空结果、不报错（未验），直接接 grep 或脚本筛，空输出就分不清是没抓到还是页上没有。只抓到外壳也算没抓到正文：商品页、搜索页的价格和库存常靠脚本加载，静态抽取只回标题和图片（未验）；视频的标题和简介只是摘要，内容在字幕或转写里。这时用手上有的其他取法（能执行脚本的页面读取、字幕或转写）再取一次；仍取不到，这一项写"没读到"并说明卡在哪一步，不写"没找到"。"没找到"只留给读过内容、确实没有的情形。
5. **交叉验证**：关键结论至少找一个独立来源；只有唯一权威来源时明说，不凑数。任务要求"至少几家、几个来源"时同理：够不上任务说的那种来源（要的是评测，手里只有单个临时案例）不算进数里；要列出来就写明它是什么、局限在哪，差的数如实报缺。
6. **处理冲突**：比较来源层级、时间、定义、样本和利益关系；裁决不了就保留冲突。研究软件或工具行为时，分开标注文档声明、绑定版本或 commit 的实现证据、当前环境复现三层；只报告实际取得的层级，缺的列进 Uncertainty；文档不能静默覆盖复现，单一版本或环境不能泛化。
7. **补缺口**：只为尚未满足的证据条件追加查询，不重复已完成的步骤。
8. **停止并汇报**。

## 停止条件

满足任一即停：所有关键主张达到预定的证据门槛，再搜不改变结论；权威资料明确回答且已核对适用范围与日期；连续两轮针对缺口的不同查询没有新的高价值证据；时间、访问权限或工具边界阻止继续且边际价值很低。

"搜到很多结果"不是停止条件。不隐瞒付费墙、登录、抓取失败或资料缺失。不为补齐来源越过授权边界。

## 输出契约

```text
结论：
- 直接回答研究问题；区分事实、来源表述和推断。

Evidence：
- [主张] — [来源标题](URL)，来源类型，发布日期或事件日期（榜单、测速、价格这类随时更新的页面写读取日期），支持范围。

Uncertainty：
- 未确认事项、冲突来源、访问限制、时效风险、只部分满足任务要求的项；没有则写"未发现重大不确定性"。
```

引用紧邻它支持的主张。没打开的搜索结果不加引用，推断不写成来源原话。

交稿前把每条引用和挨着它的句子对回那一页：句子要在这页上找得到；转述不比原文更强、更宽（原文说"不能覆盖内建安全要求"，就别写成"不能关掉某项功能"；原文没说"只有用户能做"，就别添上）；原文的限定语（尽量、可能、默认、重启后仍有效）一起带上。这页上找不到的，换成真正说了它的那页，或者改标推断、未核实。

## 改报告文件（shell 的坑）

成段中文别内联进 python 或 shell 脚本的字符串常量：正文里带半角引号的词（如 `叫 "Agent-as-Tool"`）会提前结束字符串，脚本在编译阶段就失败，文件一个字节都没动。把要插入或替换的原样文字先写成单独的 UTF-8 文件，脚本只从文件读，不在脚本里拼这段中文（未验）。

## 反思

作为 `specialist-subagents` 座位运行时，执行困难由服务从运行记录自动采集，**报告与笔记中不写反思段**（以岗位合同 `roles/web_researcher.md` 为准）。仅在无自动运行记录采集的独立宿主中单独调用、且上层契约未禁止时，若研究里遇到具体困难（失败的尝试、打不开的来源或工具、冲突的证据、说不清的契约），才在输出末尾留一段客观观察，不推根因、不提建议：

```text
Expected：
Observed：
Impact：
Evidence：
Handling：一句话，用了什么办法、结果如何
```
